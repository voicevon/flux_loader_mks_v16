# 基于 MKS Base V1.6 的 SCARA 机械臂控制系统需求与设计规格书

本文件详细记录了基于 MakerBase MKS Base V1.6 控制板开发单臂 SCARA 机械臂（用于抓取芦笋）的需求与系统设计规范。

---

## 1. 项目概述与应用场景

* **项目目标**：配置并修改 Marlin 固件，控制一台单臂 SCARA 机械臂，通过串口接收标准 G-code 笛卡尔坐标指令，实现对"芦笋"(Asparagus)的精准抓取与搬运。
* **开发路线**：采用"**Marlin 2.0+ 固件配置 + 局部逆运动学公式修改**"的路线，以兼顾系统运动控制的稳定性和客制化需求。
* **实现原则**：所有可调参数均以**具名宏（Named Macro）**定义在配置文件中，固件代码本身不硬编码数值，方便在调试阶段修改后重新编译。
* **固件源码工程位置**：实际的 Marlin 固件源代码工程与本设计文档工程平级，位于同级工作区目录 **`../Marlin`**（绝对路径：`d:\Software\antigravity\Marlin`），固件编译与配置调整均在该源码工程中进行。

## 2. 机械与运动轴配置

本系统共有 4 个核心运动轴与 1 个末端执行器，物理及电气配置如下表所示：

| 轴名称 | 物理机构与作用 | 电动执行器类型 | MKS Base V1.6 物理接口 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| **X 轴** | 大臂关节（Joint 1），控制水平面一阶旋转 | 步进电机 | **X-MOTOR** | 需要回零限位开关 |
| **Y 轴** | 小臂关节（Joint 2），控制水平面二阶旋转 | 步进电机 | **Y-MOTOR** | 需要回零限位开关 |
| **Z 轴** | 垂直升降轴，控制末端执行器上下运动 | **舵机 (Servo)** | **Servo 0 (A11 / D65)** | Z 坐标线性映射为舵机角度，见第 3.3 节 |
| **R 轴** | 末端旋转轴（Joint 3），控制夹爪世界坐标绝对朝向 | 步进电机 | **E0-MOTOR** | 需在大臂小臂旋转时自动进行逆运动学耦合补偿 |
| **夹爪 1 (头端)** | 芦笋头端抓取爪，用于夹取芦笋头部 | 舵机 (Servo) | **Servo 1 (D11)** | 使用 `M280 P1` 进行独立的开/闭动作控制 |
| **夹爪 2 (尾端)** | 芦笋尾端抓取爪，用于夹取芦笋尾部 | 舵机 (Servo) | **Servo 2 (D12)** | 使用 `M280 P2` 进行独立的开/闭动作控制 |

## 3. 控制与运动学解算要求

### 3.1 坐标系与指令规范

1. **控制指令**：上位机通过**串口**向控制板发送标准 G-code 指令，波特率 **115200 bps**。
2. **坐标输入**：G-code 采用标准的**笛卡尔直角坐标系**，格式如下：

   ```
   G1 X[x_pos] Y[y_pos] Z[z_pos] R[r_angle] F[feedrate]
   ```

   * `X`, `Y`：笛卡尔坐标下的绝对位置（单位：毫米）。
   * `Z`：垂直高度位置（单位：毫米），通过线性映射折算为 Z 轴舵机角度值，见第 3.3 节。
   * `R`：夹爪在世界坐标系中的绝对角度（单位：度）。
   * `F`：运动进给速度（单位：mm/min）。

### 3.2 逆运动学（IK）与旋转补偿

1. **大臂与小臂解算**：固件内部通过 SCARA 逆运动学算法将输入的 Cartesian XY 坐标转换为大臂关节角（theta_1）与小臂关节角（theta_2），进而控制 X 轴与 Y 轴步进电机的步数。
2. **IK 解选择**：固件固定采用 **Elbow UP 解**（小臂向外展开），不支持运行时切换。此方案为芦笋抓取场景提供最大有效工作空间。
3. **旋转朝向（R 轴）补偿**：为了在 XY 轴运动时，使夹爪在世界坐标系下的绝对朝向 phi 保持恒定或精准按 G-code 指令偏转，固件的 `inverse_kinematics()` 函数需实现如下数学解耦公式：

   ```
   theta_3(电机实际旋转角) = phi(Gcode绝对朝向) - theta_1 - theta_2
   ```

   * 该公式能自动在步进中断中补偿因大臂和小臂旋转而产生的夹爪世界朝向偏差。
4. **物理几何参数**：大臂长度（L1）和小臂长度（L2）采用**静态配置**，在固件编译前的配置文件中通过以下宏定义：

   ```cpp
   // Configuration.h
   #define SCARA_LINKAGE_1  [待填入, 单位: mm]  // 大臂长度 L1
   #define SCARA_LINKAGE_2  [待填入, 单位: mm]  // 小臂长度 L2
   ```

### 3.3 Z 轴舵机映射规范

Z 轴舵机采用**线性映射**，将 G-code 中的 Z 坐标（毫米）线性转换为舵机 PWM 角度：

```
servo_angle = (Z_mm / Z_MM_MAX) * Z_SERVO_ANGLE_MAX
            = (Z_mm / 100.0)   * 270.0
```

| 参数 | 数值 |
| :--- | :--- |
| Z 坐标范围 | 0 mm ~ 100 mm |
| 舵机角度范围 | 0° ~ 270° |
| 映射公式 | `servo_angle = Z_mm / 100.0 * 270.0` |
| 边界截断 | 超出 [0, 100] 的 Z 值在固件中 clamp 至边界 |

对应固件宏：
```cpp
#define Z_SERVO_ANGLE_MIN  0    // Z=0 mm 时舵机角度（最低位）
#define Z_SERVO_ANGLE_MAX  270  // Z=100 mm 时舵机角度（最高位）
#define Z_MM_MAX           100  // Z 坐标上限（毫米）
```

### 3.4 夹爪舵机控制规范

夹爪通过 `M280 Pn Sangle` 指令控制，角度参数以具名宏预定义，后期通过调试整定：

```cpp
// Configuration.h
#define GRIPPER1_OPEN_ANGLE   0   // Servo 1 (头端 - D11) 打开角度（°）
#define GRIPPER1_CLOSE_ANGLE  90  // Servo 1 (头端 - D11) 闭合角度（°）
#define GRIPPER2_OPEN_ANGLE   0   // Servo 2 (尾端 - D12) 打开角度（°）
#define GRIPPER2_CLOSE_ANGLE  90  // Servo 2 (尾端 - D12) 闭合角度（°）
```

典型控制指令示例：
```gcode
M280 P1 S{GRIPPER1_OPEN_ANGLE}   ; 夹爪1 打开
M280 P1 S{GRIPPER1_CLOSE_ANGLE}  ; 夹爪1 闭合
M280 P2 S{GRIPPER2_OPEN_ANGLE}   ; 夹爪2 打开
M280 P2 S{GRIPPER2_CLOSE_ANGLE}  ; 夹爪2 闭合
```

## 4. 步进电机驱动配置

### 4.1 驱动器型号与细分设置

| 参数 | 配置值 |
| :--- | :--- |
| 驱动模块型号 | **Allegro A4982**（与 A4988 引脚兼容） |
| 细分设置 | **1/16 细分**（MS1=H, MS2=H, MS3=H 跳帽满接） |
| 步进电机规格 | 标准 1.8°/步（200 步/转） |
| 基础步数/转 | 200 × 16 = **3200 步/转** |
| 基础步数/度 | 3200 / 360 ≈ **8.889 步/度** |

### 4.2 关节减速比配置

各关节电机到关节轴之间的传动减速比以具名宏定义，待机械结构确定后填入：

```cpp
// Configuration.h
#define JOINT1_GEAR_RATIO  [待填入]  // 大臂关节 (X轴) 减速比，如 3.0 表示 3:1
#define JOINT2_GEAR_RATIO  [待填入]  // 小臂关节 (Y轴) 减速比
#define JOINT3_GEAR_RATIO  [待填入]  // 末端旋转 (R轴/E0轴) 减速比
```

最终 steps/degree 计算公式：
```
steps_per_degree = (3200 / 360.0) * GEAR_RATIO
```

### 4.3 运动速度与加速度配置

> **说明**：SCARA 为连杆旋转机构，其 X、Y、R 关节轴的底层物理量均为**旋转角度（度，°）**而非笛卡尔线位移。因此固件底层电机速度和加速度的单位均为**角速度 (°/s)** 与 **角加速度 (°/s²)**。实际末端轨迹线速度由 G-code 进给率 `F`（mm/min）经运动学逆解插补动态计算。

```cpp
// Configuration.h
#define MAX_FEEDRATE_X       200  // 大臂最大角速度 (°/s)
#define MAX_FEEDRATE_Y       200  // 小臂最大角速度 (°/s)
#define MAX_FEEDRATE_E       200  // R轴最大角速度 (°/s)
#define DEFAULT_ACCELERATION 500  // 默认角加速度 (°/s^2)
#define HOMING_FEEDRATE_XY   200  // 回零角速度 (deg/min)
```

## 5. 复位与安全保护规范

### 5.1 限位开关 (Limit Switches)

系统配备 3 个独立的物理硬限位开关，接线映射如下：

* **大臂限位（Joint 1 Limit）** → 连接至 MKS 接口 **X-MIN**。
* **小臂限位（Joint 2 Limit）** → 连接至 MKS 接口 **Y-MIN**。
* **R 轴限位（Joint 3 Limit）** → 连接至 MKS 接口 **Z-MIN**。

### 5.2 回零控制流程 (Homing)

1. 系统支持标准的 `G28` 回零指令。
2. 触发 `G28` 时，**X 轴、Y 轴、R 轴（E0）三轴同时以回零速度向各自限位方向运动**，全部触发限位开关后完成坐标标定。
3. 回零完成后，固件在内部建立与上位机同步的物理绝对坐标系。
4. 回零速度通过 `HOMING_FEEDRATE_XY` 配置宏设定，应保守设置以确保安全。

> **注意**：三轴同时回零时，需确保机械结构设计允许各关节同时向限位点运动而不发生干涉，否则应在机械设计阶段规避。

### 5.3 安全保护策略

本项目采用**最小化安全实现**：

* 仅依赖物理硬限位开关作为唯一硬件保护机制。
* 不启用软限位（Soft Endstop）、急停指令（M112）扩展逻辑、运动超时检测及上电自检等附加功能。
* 安全边界由上位机的 G-code 生成逻辑保证，固件层不做额外校验。
