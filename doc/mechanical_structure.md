# SCARA 机械臂物理结构与机械参数登记表

本文件用于登记基于 MKS Base V1.6 控制的 SCARA 机械臂物理机械结构参数、同步带轮齿数、传动减速比、臂长几何尺寸及末端舵机行程等。

所有在此登记的参数将作为固件 `Configuration.h` 中配置宏（Macro）的唯一权威数据源。

## 1. 关节传动与几何结构参数

### 1.1 大臂关节（Joint 1 / X 轴电机）
* **传动机构形式**：同步带减速传动
* **主动轮齿数 ($Z_{1\_in}$)**：`20` 齿 (20T)
* **从动轮齿数 ($Z_{1\_out}$)**：`128` 齿 (128T)
* **关节减速比 ($i_1$)**：`6.4 : 1` （计算公式：$128 / 20 = 6.4$）
* **大臂物理长度 ($L_1$)**：`300` mm
* **限位开关与零位**：物理接线至 **X-MIN**，触发时大臂基准角度 $\theta_{1\_home} = \mathbf{90^\circ}$

### 1.2 小臂关节（Joint 2 / Y 轴电机）
* **传动机构形式**：同步带减速传动
* **主动轮齿数 ($Z_{2\_in}$)**：`20` 齿 (20T)
* **从动轮齿数 ($Z_{2\_out}$)**：`84` 齿 (84T)
* **关节减速比 ($i_2$)**：`4.2 : 1` （计算公式：$84 / 20 = 4.2$）
* **小臂物理长度 ($L_2$)**：`300` mm
* **限位开关与零位**：物理接线至 **Y-MIN**，触发时小臂相对大臂夹角 $\theta_{2\_home} = \mathbf{0^\circ}$（完全顺向伸直重合）

### 1.3 末端旋转轴（Joint 3 / R 轴 / E0 电机）
* **传动机构形式**：同步带减速传动
* **主动轮齿数 ($Z_{3\_in}$)**：`20` 齿 (20T)
* **从动轮齿数 ($Z_{3\_out}$)**：`56` 齿 (56T)
* **关节减速比 ($i_3$)**：`2.8 : 1` （计算公式：$56 / 20 = 2.8$）
* **限位开关与零位**：物理接线至 **Z-MIN**，触发时末端相对小臂夹角 $\phi_{home} = \mathbf{0^\circ}$（与大臂、小臂在同一条直线上完全重合，世界坐标方向为 90°）

## 2. 升降轴与末端执行器（舵机）参数

### 2.1 Z 轴升降机构 (Servo 0 / A11 / D65 Pin)
* **执行器类型**：`270°` 舵机 (Servo)
* **物理行程范围**：`0 mm ~ 100 mm`
* **角度映射对应关系**：
  * $Z = 0\text{ mm}$ 时对应舵机角度：`0`° (最低点)
  * $Z = 100\text{ mm}$ 时对应舵机角度：`270`° (最高点)
  * 线性计算公式：$\text{servo\_angle} = \frac{Z_{\text{mm}}}{100.0} \times 270.0$

### 2.2 抓取夹爪 1 - 头端 (Servo 1 / D11 Pin)
* **完全打开角度 (`GRIPPER1_OPEN_ANGLE`)**：`0`°
* **抓取闭合角度 (`GRIPPER1_CLOSE_ANGLE`)**：`90`°

### 2.3 抓取夹爪 2 - 尾端 (Servo 2 / D12 Pin)
* **完全打开角度 (`GRIPPER2_OPEN_ANGLE`)**：`0`°
* **抓取闭合角度 (`GRIPPER2_CLOSE_ANGLE`)**：`90`°

## 3. 电机细分与 Marlin 步数转换基准表

* **电机转圈步数**：$200 \times 16 = 3200\text{ 步/转}$
* **电机无减速基础角度分辨率**：$3200 / 360 = 8.88888889\text{ 步/度}$
