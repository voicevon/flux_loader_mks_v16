# SCARA 机械臂物理结构与机械参数登记表

本文件用于登记基于 **MKS Base V1.6** 控制的单臂 SCARA 机械臂（用于芦笋抓取搬运）物理机械结构参数、同步带轮齿数、传动减速比、臂长几何尺寸、电气引脚接口排布及末端执行器行程。

所有在此登记的参数作为固件 `Configuration.h`、上位机 `LoaderConfig` 的唯一权威物理基准数据源。

---

## 1. MKS Base V1.6 电气接线与接口排布对照表

MKS Base V1.6 控制板采用 ATmega2560 主控，板载 5 路 A4982 步进驱动器及多路 Servo/限位接口。经过硬件实测与逻辑验证，物理接口排布与分配如下：

### 1.1 步进电机接口排布（板载从左至右）

| 接口丝印 | 实际控制对象 | 电气驱动状态 | 关键说明 |
| :--- | :--- | :--- | :--- |
| **X-MOTOR** | **大臂关节 (Joint 1)** | A4982 驱动通道 1 | 水平基座一阶旋转，步距角 1.8°，1/16 细分 |
| **Y-MOTOR** | **小臂关节 (Joint 2)** | A4982 驱动通道 2 | 水平肘关节二阶旋转，步距角 1.8°，1/16 细分 |
| **Z-MOTOR** | **[空置保留]** | A4982 驱动通道 3 | **注意：Z 轴由 Servo 0 舵机控制升降，此步进插座切勿插接！** |
| **E0-MOTOR** | **末端旋转轴 (R 轴 / Joint 3)** | A4982 驱动通道 4 | **末端独立旋转步进电机接此接口**；固件映射为 Extruder 0 |
| **E1-MOTOR** | **[备用]** | A4982 驱动通道 5 | 预留备用 |

> **排线防呆提醒**：
> 初始装配调试时极易误插到 `Z-MOTOR` 导致末端无动作。必须严格将末端旋转步进电机插入板载第 4 个插座 **`E0-MOTOR`**。

### 1.2 舵机与限位开关接口排布

| 硬件功能 | 接口位置与引脚 | 控制指令 / 信号 | 说明 |
| :--- | :--- | :--- | :--- |
| **Z 轴垂直升降** | **Servo 0 (A11 / D65)** | `M280 P0 S[angle]` | 270° 舵机线性驱动丝杠升降 (0~100mm) |
| **夹爪 1 (芦笋头端)** | **Servo 1 (D11)** | `M280 P1 S[0/90]` | 抓取头端，打开 0°，闭合 90° |
| **夹爪 2 (芦笋尾端)** | **Servo 2 (D12)** | `M280 P2 S[0/90]` | 抓取尾端，打开 0°，闭合 90° |
| **大臂原点限位** | **X-MIN** | `M119` (x_min) | 触发时大臂指向世界 +Y 方向 ($\theta = 90^\circ$) |
| **小臂原点限位** | **Y-MIN** | `M119` (y_min) | 触发时小臂与大臂平直重合 ($\psi = 0^\circ$) |
| **R 轴旋转限位** | **Z-MIN** | `M119` (z_min) | 触发时末端执行器与小臂同向指向正前方 |

## 2. 关节传动比与运动几何结构

### 2.1 大臂关节（Joint 1 / X 轴电机）
* **传动机构形式**：同步带减速传动
* **主动轮齿数 ($Z_{1\_in}$)**：`20` 齿 (20T)
* **从动轮齿数 ($Z_{1\_out}$)**：`128` 齿 (128T)
* **关节减速比 ($i_1$)**：`6.4 : 1`（$128 / 20 = 6.4$）
* **大臂物理长度 ($L_1$)**：`300` mm
* **限位与机械零点**：接 **X-MIN**，机械零位角度 $\theta_{\text{home}} = \mathbf{90.0^\circ}$（指向世界坐标系 $+Y$ 轴正向）

### 2.2 小臂关节（Joint 2 / Y 轴电机）
* **传动机构形式**：同步带减速传动
* **主动轮齿数 ($Z_{2\_in}$)**：`20` 齿 (20T)
* **从动轮齿数 ($Z_{2\_out}$)**：`84` 齿 (84T)
* **关节减速比 ($i_2$)**：`4.2 : 1`（$84 / 20 = 4.2$）
* **小臂物理长度 ($L_2$)**：`300` mm
* **限位与机械零点**：接 **Y-MIN**，机械零位相对夹角 $\psi_{\text{home}} = \mathbf{0.0^\circ}$（与大臂完全伸直共线，末端指向 $(X=0, Y=600)$）

### 2.3 末端旋转轴（Joint 3 / R 轴 / E0 电机）
* **传动机构形式**：同步带减速传动
* **主动轮齿数 ($Z_{3\_in}$)**：`20` 齿 (20T)
* **从动轮齿数 ($Z_{3\_out}$)**：`56` 齿 (56T)
* **关节减速比 ($i_3$)**：`2.8 : 1`（$56 / 20 = 2.8$）
* **限位与基准状态**：接 **Z-MIN**。当电机处于物理 0 位时，末端夹爪沿小臂中轴线指向正前方。

### 2.4 R 轴的世界坐标与物理电机角关系
* **小臂在世界坐标系中的方位角**：
  $$\phi_{\text{forearm}} = \theta + \psi$$
* **末端夹爪世界绝对朝向角**：
  $$R_{\text{world}} = \phi_{\text{forearm}} + \alpha_{\text{motor}} = (\theta + \psi) + \alpha_{\text{motor}}$$
* **机械零点状态 (Home)**：
  $\theta_0 = 90.0^\circ, \psi_0 = 0.0^\circ, \alpha_{\text{motor}} = 0.0^\circ \implies R_{\text{world\_home}} = 90.0^\circ$（指向正前方）。

## 3. 升降轴与末端抓取机构参数

### 3.1 Z 轴升降机构 (Servo 0 / A11 Pin)
* **执行机构**：`270°` 大扭矩舵机 + 升降丝杠滑台
* **有效升降行程**：`0 mm ~ 100 mm`
* **高度-角度映射**：
  * 最低工作位 ($Z = 0\text{ mm}$) 对应舵机角度：`0.0°`
  * 最高安全位 ($Z = 100\text{ mm}$) 对应舵机角度：`270.0°`
  * 线性映射公式：
    $$\text{servo\_angle} = \frac{Z_{\text{mm}}}{100.0} \times 270.0$$

### 3.2 抓取夹爪 1 - 头端 (Servo 1 / D11 Pin)
* **完全张开角度 (`GRIPPER1_OPEN_ANGLE`)**：`30.0°`（实测整定）
* **夹紧闭合角度 (`GRIPPER1_CLOSE_ANGLE`)**：`0.0°`（实测整定，抓紧芦笋）

### 3.3 抓取夹爪 2 - 尾端 (Servo 2 / D12 Pin)
* **完全张开角度 (`GRIPPER2_OPEN_ANGLE`)**：`30.0°`（实测整定）
* **夹紧闭合角度 (`GRIPPER2_CLOSE_ANGLE`)**：`0.0°`（实测整定，抓紧芦笋）

## 4. 步进电机细分与运动参数标定基准

全机采用 **1.8°/步** 步进电机，A4982 驱动器开启 **1/16 细分**：
* **电机每整转脉冲数**：$200 \times 16 = 3200\text{ 步/转}$
* **未减速基础角分辨率**：$3200 / 360 = 8.88888889\text{ 步/度}$

### 4.1 脉冲当量表 (Steps per Degree)

| 运动轴 | 驱动接口 | 传动减速比 ($i$) | Marlin `DEFAULT_AXIS_STEPS_PER_UNIT` (步/度) |
| :--- | :--- | :--- | :--- |
| **X 轴 (大臂 Joint 1)** | X-MOTOR | **6.4** | $8.8889 \times 6.4 = \mathbf{56.8889}$ |
| **Y 轴 (小臂 Joint 2)** | Y-MOTOR | **4.2** | $8.8889 \times 4.2 = \mathbf{37.3333}$ |
| **R 轴 (末端 Joint 3)** | E0-MOTOR | **2.8** | $8.8889 \times 2.8 = \mathbf{24.8889}$ |

### 4.2 调优实测运动参数（上位机与固件对齐）

| 参数项 | 参数值 | 说明 |
| :--- | :--- | :--- |
| **大臂点动进给率** | `6000.0 deg/min` (100°/s) | 兼顾大惯量平稳与快速响应 |
| **小臂点动进给率** | `15000.0 deg/min` (250°/s) | 小臂惯量较小，提速至 250°/s，动作迅捷 |
| **R 轴点动进给率** | `60000.0 deg/min` (1000°/s) | 末端轻量轴，毫秒级快速旋转定位 |
| **R 轴底层限速释放** | `M203 E1200` (1200°/s) | 开机初始化解除固件 EEPROM 挤出机低速限制 |
| **冷挤出使能** | `M302 P1` | 允许常温直接驱动 E0 步进电机 |
| **默认角加速度** | `500.0 deg/s²` | 消除启停柔性振动 |
